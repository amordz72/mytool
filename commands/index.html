HiLink — Stable + Build بضغطة واحدة

ضع الملف داخل مجلد مشروع HiLink القديم ثم شغله. يجلب stable-v0.5-main-sync، ينظف الكود القديم، ينفذ npm ci، يبني Setup وPortable، ثم يفتح release.

تحميل HILINK_STABLE_BUILD.bat

HiLink — تحديث Stable فقط

لما تريد فقط جعل نفس مجلد المشروع مطابقًا لآخر Stable بدون Build.

تحميل HILINK_GET_STABLE.bat

HiLink — Build فقط

إذا كان السورس عندك جاهز وتريد فقط تثبيت الاعتماديات وبناء نسخة Windows.

تحميل HILINK_BUILD.bat
تنبيه: ملف Stable يحذف التعديلات المحلية غير المحفوظة داخل مشروع HiLink قبل إرجاعه للحالة المستقرة. استعمله عندما تكون متأكدًا أنك لا تحتاج تغييرات محلية غير مرفوعة.
