# Flexy Policy Source of Truth

هذا المجلد هو المرجع التنفيذي الثابت لمنطق Flexy داخل MyTool Dev.

- `CURRENT-POLICY.md`: القواعد الحالية.
- `SOURCES.md`: المصادر التاريخية والتعارضات وحالة كل قرار.
- `current-policy.json`: نسخة منظمة تقرأها واجهة التوثيق.

القاعدة: Developer والمشاريع القديمة مصادر أدلة وتاريخ، لكن التنفيذ الجديد يبدأ من هذا المجلد ثم يراجع الكود وقاعدة البيانات الحالية.
