# Firebase plan for MyTool

## القرار
اعتماد Firebase على خطة **Blaze (Pay as you go)** لمشروع MyTool بدل الاعتماد على الخطة المجانية فقط.

## الهدف
- حماية بيانات المحل والمخزون والمبيعات.
- تفعيل النسخ الاحتياطية التلقائية وإمكانية الاسترجاع عند الحاجة.
- عدم ربط أمان البيانات بفكرة تسجيل الدخول الدوري؛ Firebase لا يحذف البيانات لمجرد عدم فتح المشروع أسبوعيًا.

## خطة النسخ الاحتياطي
- نسخة احتياطية تلقائية: **مرة كل أسبوع**.
- الاحتفاظ بآخر **4 نسخ احتياطية**.
- مراجعة الاسترجاع لاحقًا عند تجهيز بيانات فعلية مهمة.

## التكلفة المتوقعة في البداية
- Blaze ليس اشتراكًا شهريًا ثابتًا؛ الدفع حسب الاستهلاك.
- مع استخدام MyTool الحالي والمتوقع في البداية، التكلفة المرجحة منخفضة جدًا، وغالبًا في حدود **0 إلى 1 دولار شهريًا** ما دام الاستهلاك وحجم البيانات صغيرين.
- تتم مراجعة التكلفة عندما يكبر عدد المستخدمين أو حجم البيانات أو عدد العمليات.

## ملاحظة تنفيذية
عند تجهيز Firebase للمشروع، نفعّل Billing/Blaze أولًا ثم نضبط سياسة النسخ الاحتياطي الأسبوعية والاحتفاظ بأربع نسخ.
