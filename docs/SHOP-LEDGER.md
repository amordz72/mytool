# سجل حساب المحل — MyTool

الحالة: `PENDING`

## الهدف
إضافة خدمة بسيطة داخل MyTool لتسجيل حركات المحل القادمة من مجموعة الخدام، ثم استعمالها لاحقًا في الجرد.

## المطلوب مبدئيًا
- تسجيل كل حركة مع: التاريخ، الوقت، اسم العامل/الشخص، الصنف أو الوصف، المبلغ، ونوع العملية (بيع / شراء / مصروف / غير محدد).
- تجميع حساب كل شخص على حدة وعرض إجماليه.
- إظهار الإجمالي العام للفترة.
- في مرحلة لاحقة ربط هذه الحركات مع جرد/إغلاق الصندوق والمخزون.
- عدم وضع أسماء الزبائن أو أرقام الهواتف أو المبالغ الفعلية أو أي بيانات مالية حساسة داخل GitHub العام؛ البيانات الحقيقية تبقى محليًا أو في Google Drive الخاص.

## ملاحظة تنفيذية
ابدأ بأبسط نسخة: إدخال حركة + قائمة الحركات + مجموع حسب الشخص. لا تُدخل نظام محاسبة كامل في المرحلة الأولى.
