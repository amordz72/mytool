مرحلة اختبار الواجهة فقط

آخر نتيجة حقيقية

HTTP 500

هاتف أندرويد · 09 أكتوبر 2026 · 14:14

استقبل الاختصار رد خطأ 500، لكن جسم الاستجابة ونوعها غير محفوظين. لا يمكن الجزم بمصدر الخطأ.

النتيجة: لا INFO · لا تفعيل بطاقة · لا إعادة محاولة

ما الذي نعرفه من البرنامج؟

الاستعلام: POST /api/epay/checkNdAdsl

التفعيل: POST /api/epay/voucherAdsl

العقد مستخرج من AppImage سنة 2023 ولم تثبت صلاحيته التشغيلية أو شروط استخدامه التجاري حاليًا.

الاستعلام فقط — كود جاهز للمراجعة

النموذج يخص Node.js وليس تنفيذًا من المتصفح. لا يتضمن رقمًا حقيقيًا أو PIN.

https://mobile-pre.at.dz/api/epay/checkNdAdsl

// Lookup only — Node.js 22+ — run in an authorized environment.
const nd = process.env.IDOOM_ND?.trim()
if (!nd || !/^\d{8,12}$/.test(nd)) throw new Error('Set a valid IDOOM_ND')
if (process.env.IDOOM_LOOKUP_CONFIRM !== 'YES') {
  throw new Error('Confirm line-owner consent and permitted API use first')
}
const response = await fetch('https://mobile-pre.at.dz/api/epay/checkNdAdsl', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ nd, service: 'Voucher' }),
  redirect: 'manual',
  signal: AbortSignal.timeout(12000)
})
const type = response.headers.get('content-type') ?? ''
console.log({ httpStatus: response.status, contentType: type })
if (type.includes('application/json')) {
  const data = await response.json()
  console.log({ apiCode: data?.code, hasInfo: Boolean(data?.INFO) })
} else {
  console.log('Non-JSON response: stop, do not retry')
}
// No voucher activation. No PIN. No automatic retry.

لتشغيله مستقبلًا يلزم Node.js 22+، وIDOOM_ND وIDOOM_LOOKUP_CONFIRM=YES داخل بيئة مصرح بها. لا تشغله من تلقاء نفسه هنا.

متطلبات التنفيذ الحقيقي

إذن الاستعلام والتفويض

تأكيد شروط استخدام واجهة اتصالات الجزائر وإذن صاحب رقم الخط قبل طلب آخر.

استعلام lookup ناجح

رد JSON حيّ يحتوي INFO بعد طلب واحد فقط وبدون retry؛ HTTP 500 ليس نجاحًا.

تحديد بيئة الاتصال

تجربة سيرفر مصرح بها أولًا؛ Station Connect فقط عند ثبوت حاجة تشغيل محلي.

حماية البيانات

لا أرقام زبائن ولا PIN ولا جلسات داخل GitHub أو روابط المشاركة أو السجلات.

إذن منفصل لتفعيل البطاقة

voucherAdsl مغلق في هذه الواجهة. تفعيل حقيقي يحتاج موافقة صريحة وتسوية حالة UNKNOWN.

محاكاة عرض النتائج

تجربة شكل الواجهة فقط. لا ترسل HTTP ولا تحفظ بيانات.
