الثابت في ملفات، والمتغير في قاعدة البيانات

Discovery يعرف نوع/مجموعة العرض. بعدها نعرض Catalog ثابت مجرب، ثم Execution Map ثابت للمسار المؤكد.

التدفق

Phone ↓ Discovery / classification ↓ Static Catalog ↓ Selected offer ↓ Static Execution Map ↓ Dynamic Job in DB ↓ Station executes ↓ Result / history in DB

ملفات ثابتة

Git/versioned
  • operator/family/amount
  • display name
  • network index المثبت
  • execution template المثبت
  • ترتيب العرض

قاعدة بيانات

Dynamic only
  • station/modem/sim current state
  • balance
  • job
  • result
  • history/events

شكل الملفات المقترح

flexy-config/ catalogs/ mobilis-sama-mix.json mobilis-sama-talk.json mobilis-sama-net.json mobilis-pixx.json execution/ mobilis-sama.json mobilis-arsselli.json
أي قيمة غير مثبتة حيًا لا تدخل الملف كأنها حقيقة؛ تبقى REVIEW حتى الاختبار.

فصل الهوية عن التنفيذ

العرض يُعرف بـoperator + family + amount. أما network_index أو مصدر Sama/Arsselli فهي طريقة تنفيذ، وليست هوية العرض نفسها.
