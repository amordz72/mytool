ليس بديلًا عن HiLink أو USSD. دوره باب إنترنت آمن + تخزين الحالة الحية والـJobs حتى MyTool والكمبيوتر يلتقيا في مكان واحد.

الجديد المقترح

station-gateway

Function جديدة فقط للمحطات، لا علاقة لها برفع الصور ولا بواجهة المتصفح.

شكل الـFunction المقترح

POST /functions/v1/station-gateway/enroll GET/POST /functions/v1/station-gateway/status POST /functions/v1/station-gateway/heartbeat POST /functions/v1/station-gateway/modems/report POST /functions/v1/station-gateway/jobs/next POST /functions/v1/station-gateway/jobs/{id}/complete

قد ننفذها Function واحدة مع routing داخلي أو أكثر من Function؛ القرار النهائي قبل التنفيذ. المهم أن العقد يبقى ثابتًا للـAgent.
