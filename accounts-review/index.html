🧩 هوية ودمج الحسابات

المصدر يُحدد أولًا، ثم يمنع التكرار داخل نفس المنصة، وبعدها تُجمع حسابات نفس العميل بين المنصات. الهاتف/البريد/المستخدم القوي يربط تلقائيًا، والحالات القريبة تذهب للمراجعة.
فتح الدمج والمراجعة
الملفات نفسها لا تُرفع. تُقرأ محليًا، ثم تُحفظ النتائج والسجلات الموحّدة في Supabase مع نسخة IndexedDB للعمل دون اتصال. Supabase: جاري التحقق…
لا توجد بيانات محفوظة بعد.
استخدم زر ملف في الشريط السفلي لإضافة CSV أو Excel أو JSON أو TXT.
