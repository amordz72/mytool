# MyTool

مجموعة أدوات عمل بسيطة لعمر، تشمل معالج البطاقات، أدوات فليكسي، روابط البرامج، QR، وحساب المحل.

## حساب المحل
واجهة أولية موجودة داخل `shop/` ومربوطة بـ Supabase مع Vue من المتصفح.

## الأمان
البيانات التشغيلية الحقيقية لا تُحفظ داخل GitHub العام. يتم استخدام Supabase Auth + RLS، ولا يجب وضع أي Secret key أو `service_role` داخل المستودع.
