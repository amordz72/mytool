## تشغيل MyTool مباشرة

**الرابط الرئيسي:** https://amordz72.github.io/mytool/

من أي هاتف أو كمبيوتر، افتح الرابط أعلاه للوصول إلى MyTool. لا تحتاج للبحث داخل ملفات GitHub حتى تجد صفحة التشغيل.

مجموعة أدوات عمل بسيطة لعمر، تشمل معالج البطاقات، أدوات فليكسي، روابط البرامج، QR، وحساب المحل.

## حساب المحل
واجهة أولية موجودة داخل `shop/` ومربوطة بـ Supabase مع Vue من المتصفح.

## الأمان
البيانات التشغيلية الحقيقية لا تُحفظ داخل GitHub العام. يتم استخدام Supabase Auth + RLS لمسار حساب المحل، ولا يجب وضع أي Secret key أو `service_role` داخل المستودع.

مسار دخول الأدوات العامة مستقل تصميميًا عن حساب المحل، ولا يجب أن يمنح دخول الأدوات العامة صلاحية الوصول إلى بيانات المحل الحساسة.
