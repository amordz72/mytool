# مهام معالج البطاقات

آخر تحديث: 2026-08-26

## الحالة

- [x] **فصل محتوى الأقسام**: كل تبويب (Mobilis / Token Store / نص عادي) يحتفظ بنصه الخاص أثناء التنقل بين التبويبات داخل الصفحة، ولا ينسخ محتوى تبويب إلى آخر.
- [x] **زر مسح المحتوى**: إضافة زر لمسح محتوى التبويب الحالي ونتيجته واسم الملف المرتبط به فقط، بدون الحاجة إلى تحديث الصفحة كاملة.
- [ ] **حفظ مؤقت للنص الأصلي بعد تحديث/إغلاق الصفحة**: غير منفذ حاليًا لأن طريقة الحفظ لم تُحسم بعد. القرار المطلوب لاحقًا: Session Storage (ينتهي مع الجلسة) أو Local Storage (يبقى بعد إغلاق المتصفح).

## ملاحظة

المهمة الثالثة لا تُنفذ قبل تحديد السلوك المطلوب بوضوح، حتى لا يبقى نص حساس محفوظًا في المتصفح لمدة أطول من المقصود.
