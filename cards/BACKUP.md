# النسخ الاحتياطي لإعدادات MyTool

آخر تحديث: 2026-09-10

## الحالة

`IMPLEMENTED` — بانتظار اختبار الاستيراد/التصدير عمليًا من الهاتف.

## الهدف

صيغ المصادر وإعدادات معالج البطاقات محفوظة داخل `localStorage` في المتصفح. هذا مناسب للعمل اليومي لكنه ليس أرشيفًا مضمونًا؛ قد تضيع البيانات عند مسح بيانات المتصفح أو تغيير الهاتف/المتصفح.

لذلك يوفر MyTool صفحة **النسخ الاحتياطي** التي تجمع الإعدادات والصيغ في ملف واحد قابل للتصدير والاستيراد.

## ماذا يحتوي ملف Backup؟

حاليًا يشمل:

- صيغ المصادر المخصصة `mytool.cards.customSources.v1`.
- إزالة الفراغات.
- التعرف التلقائي.
- المعالجة التلقائية.
- إظهار الخيارات السريعة.
- إعداد إزالة التكرارات في الاستخراج الذكي.
- قواعد تجاهل الاستخراج الذكي.
- إعدادات إظهار تقسيم الملفات لكل نوع.

ولا يشمل:

- أكواد البطاقات.
- النصوص الملصقة أو الملفات المصدرية.
- بيانات `sessionStorage`.
- سجل بطاقات أو بيانات حساسة مستقبلية غير مصرح بها صراحة.

## الصيغة

يُصدر MyTool ملف JSON واحد باسم مشابه:

```text
MyTool_Backup_2026-09-10_08-30.json
```

JSON مختار بدل TXT غير المنظم لأنه يسمح باسترجاع الإعدادات بدون تخمين أو خلط بين الحقول. الملف نفسه نصي ويمكن فتحه ونسخ محتواه يدويًا.

مثال مبسط وهمي:

```json
{
  "format": "mytool-cards-backup",
  "version": 1,
  "createdAt": "2026-09-10T07:30:00.000Z",
  "scope": "settings-and-source-formats-only",
  "data": {
    "localStorage": {
      "mytool.cards.autoDetect": "1",
      "mytool.cards.smartDedupe": "1",
      "mytool.cards.customSources.v1": "[...]"
    }
  }
}
```

> المثال لا يحتوي أي كود بطاقة حقيقي.

## التصدير

من معالج البطاقات:

`💾 نسخ احتياطي → تصدير نسخة احتياطية الآن`

بعد نجاح التنزيل يسجل MyTool تاريخ آخر نسخة وبصمة الإعدادات التي تم تصديرها.

## التنبيه في الصفحة الرئيسية

يعرض MyTool حالة النسخ الاحتياطي دائمًا:

- إذا لم توجد نسخة سابقة: تنبيه لإنشاء أول Backup.
- إذا تغيرت الإعدادات أو الصيغ بعد آخر Backup: تنبيه أن النسخة أصبحت قديمة.
- إذا كانت البصمة الحالية مساوية لآخر Backup: يظهر أن النسخة محدثة مع تاريخها.

المقارنة تتم على محتوى الإعدادات نفسها، وليس اعتمادًا فقط على تاريخ آخر تعديل.

## الاستيراد

طريقتان:

1. اختيار ملف `.json` أو `.txt` يحتوي نسخة MyTool.
2. فتح ملف النسخة كنص ولصق محتواه في مربع الاستيراد.

قبل الاسترجاع يعرض MyTool ملخصًا يتضمن عدد صيغ المصادر وعدد إعدادات التقسيم والإعدادات العامة.

عند التأكيد، يتم **استبدال نطاق الإعدادات المدعوم** بما يوجد في النسخة. لا يلمس الاستيراد بيانات أخرى في `localStorage` خارج قائمة MyTool المسموح بها.

## حماية الاستيراد

- الملف يجب أن يحمل `format: mytool-cards-backup`.
- الإصدار المدعوم حاليًا هو `version: 1`.
- المفاتيح غير المعروفة يتم تجاهلها.
- لا يتم تنفيذ أي JavaScript من الملف؛ المحتوى يقرأ كـ JSON فقط.
- يجب وجود إعداد واحد صالح على الأقل قبل السماح بالاستيراد.

## قاعدة تطوير مستقبلية

أي إعداد جديد نريد اعتباره جزءًا من Backup يجب إضافته صراحة إلى قائمة المفاتيح الآمنة في `cards/backup.js`. لا نعتمد نسخ كل `localStorage` تلقائيًا حتى لا تدخل بيانات غير مقصودة أو حساسة مستقبلًا.
